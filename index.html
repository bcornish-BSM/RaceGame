Student interface

Your script can use the MechanicsLab object to access the canvas, drawing context, keyboard state, simulation controls and readout fields. See the starter example below.

Starter script: student.js

Create a file called student.js beside index.html. This minimal example draws a circle and moves it with the arrow keys. It is a starting point, not a complete physics engine.

MechanicsLab.setStudentStatus("Student script loaded.");

let x = 100;
let y = 100;
let vx = 0;
let vy = 0;

MechanicsLab.onReset(() => {
  x = 100; y = 100; vx = 0; vy = 0;
});

MechanicsLab.onUpdate((dt, keys) => {
  // Replace this simple example with your own force model.
  const acceleration = 180; // pixels/s²
  if (keys.ArrowRight) vx += acceleration * dt;
  if (keys.ArrowLeft)  vx -= acceleration * dt;
  if (keys.ArrowDown)  vy += acceleration * dt;
  if (keys.ArrowUp)    vy -= acceleration * dt;

  x += vx * dt;
  y += vy * dt;

  // Keep the circle inside the canvas for this starter example.
  x = Math.max(10, Math.min(MechanicsLab.width - 10, x));
  y = Math.max(10, Math.min(MechanicsLab.height - 10, y));

  MechanicsLab.setReadout({ x, y, vx, vy });
});

MechanicsLab.onDraw((ctx) => {
  ctx.beginPath();
  ctx.arc(x, y, 10, 0, Math.PI * 2);
  ctx.fillStyle = "#69d5c4";
  ctx.fill();
});

For real A-level mechanics, define your units and coordinate system explicitly. The starter example uses screen pixels and a simple acceleration rule.
